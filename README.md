# Eche

Open-source Discord bot + desktop control panel.

**Four forks only** (local + GitHub monorepo):

| Fork | Folder | What |
|------|--------|------|
| **App (portable)** | `eche/` | Run `Eche.exe` after build |
| **App source** | `eche_source/` | Code + `BUILD.bat` / `SETUP_AND_BUILD.bat` |
| **Installer (portable)** | `eche_installer/` | Run `dist\Eche-Installer.exe` |
| **Installer source** | `eche_installer_source/` | Wizard code + `build.bat` |
